# StreamList

**Просмотр, правка и очистка скрытых потоков данных NTFS в Total Commander**

Версия 1.2.1 · Плагин файловой системы (WFX) для 32 и 64 бит · Автор: Native2904 · Лицензия: MIT

Главы опираются друг на друга: от основ альтернативных потоков данных через работу с отдельными файлами до анализа целых дисков с помощью Everything. Тем, кто уже знаком со StreamList, назначения клавиш, поля, а также настройки и журнал собраны в главах 5, 10 и 12.

---

## 1. Что такое поток данных?

NTFS хранит содержимое файла в потоке данных. Помимо этого основного потока файл может иметь сколько угодно дополнительных именованных потоков – **альтернативных потоков данных** (*Alternate Data Streams*, ADS), далее просто **потоков**. Проводник их не показывает, и отображаемый размер файла их не учитывает. При копировании или перемещении в пределах NTFS они тем не менее остаются с файлом.

Чаще всего они встречаются в виде отметки загрузки, которую часто называют *Mark of the Web*: браузеры добавляют к каждому загруженному файлу поток `Zone.Identifier`. В нём записана зона безопасности, из которой получен файл, и обычно адрес источника. На нём основано предупреждение, которое Windows показывает при открытии таких файлов.

Увидеть это можно в командной строке с помощью `dir /r`:

| Размер | Имя |
|---:|---|
| 4 858 880 | `alrext.exe` |
| 52 | `alrext.exe:Zone.Identifier:$DATA` |
| 87 552 | `ChmLib.dll` |
| 52 | `ChmLib.dll:Zone.Identifier:$DATA` |

Строки вида `файл:имя:$DATA` – это потоки; значит, у `alrext.exe` есть поток `Zone.Identifier` размером 52 байта.

StreamList показывает эти потоки в Total Commander как обычные записи, которые можно просматривать, править, создавать и удалять.

## 2. Установка

Требуются Total Commander 7.5 или новее, Windows 7 или новее и **Everything 1.5** от voidtools с индексированными свойствами потоков (настройка – в главе 8). Откройте архив в Total Commander и подтвердите установку; после этого StreamList появится в **Сетевом окружении**.

Главы 3–7 описывают работу с отдельными папками и файлами, глава 8 – анализ целых дисков через Everything.

## 3. Первый обзор

Запись **StreamList** в Сетевом окружении показывает диски NTFS системы и два списка со значком лупы:

| Имя | Потоки |
|---|---:|
| 🔍 `! Свободный поиск` | |
| 🔍 `! Все файлы с потоками` | |
| 🔍 `! Загрузки (Zone.Identifier)` | |
| 📁 `C` | ∑ 58 448 |
| 📁 `D` | ∑ 312 |

Списки рассматриваются в главе 8. Сначала – о том, как выглядят обычные папки.

## 4. Обзор папки

Внутри StreamList папка выглядит как обычно, и операции с файлами работают как в обычной панели: F5 копирует, F6 перемещает, F8 удаляет настоящие файлы (глава 6). Отличие одно: **Enter на файле открывает не сам файл, а его потоки.**

Какие файлы вообще имеют потоки, показывает режим колонок, который StreamList включает при входе:

| Имя | Размер | Потоки | Содержимое | Источник |
|---|---:|---:|---|---|
| 📁 `Tools` | `<DIR>` | ∑ 31 | | |
| 📦 `setup.zip` | 2 418 330 | 1 | Zone.Identifier | https://example.org/… |
| 📄 `заметка.txt` | 1 204 | 2 | Comment, один | |
| 📄 `картинка.png` | 88 112 | | | |

- **Потоки** – число потоков у файла. У папок здесь с пометкой `∑` указано число файлов с потоками во всём поддереве; это значение берётся из индекса Everything (глава 8).
- **Содержимое** перечисляет имена потоков.
- **Источник** для загруженных файлов содержит адрес из `Zone.Identifier`.

Пустые поля, как у `картинка.png`, означают, что потоков нет.

Если потоки есть у **самой папки**, вверху дополнительно появляется запись `[Streams]`. О ней рассказывает глава 5.

## 5. Список потоков файла

Enter на `заметка.txt` открывает список потоков этого файла:

| Имя | Размер | Содержимое |
|---|---:|---|
| 📄 `Comment.txt` | 7 | Счёт |
| 📄 `один.txt` | 16 | первый поток |

Колонка **Содержимое** здесь показывает первую строку текста каждого потока; двоичные потоки отображаются шестнадцатеричной последовательностью, например `4D 5A 90 00 …`.

Расширение `.txt` заимствовано: на самом деле потоки называются `Comment` и `один`. StreamList добавляет его к текстовым потокам без собственного расширения, чтобы после копирования их можно было открыть обычными программами. При правке, удалении и переименовании StreamList всегда работает с настоящим именем. Потоки с расширением (например, `Zone.Identifier`) и двоичные потоки сохраняют своё имя; параметр `TxtExtension=0` отключает это поведение.

Работа со списком потоков ведётся привычными функциональными клавишами:

| Клавиша | Действие |
|---|---|
| F3 | просмотр потока |
| F4 | правка потока – при сохранении он записывается обратно в файл |
| F5 | копировать потоки наружу; они становятся обычными файлами |
| F5 из другой панели | копировать обычные файлы внутрь; они становятся потоками |
| F7 | создать новый пустой поток |
| Shift+F6 | переименовать поток |
| F6 | переместить потоки наружу |
| F8 | удалить потоки |
| Alt+Enter | сведения о потоке |

Backspace возвращает в папку. Какие правила защиты при этом действуют, описано в следующей главе.

### Потоки у папок

Потоки могут быть не только у файлов, но и у папок. Они ещё менее заметны, чем потоки файлов, и поэтому иногда используются как тайник. Поскольку Enter на папке ведёт внутрь папки, StreamList показывает их через отдельную запись:

| Имя | Потоки |
|---|---:|
| 📁 `[Streams]` | 2 |
| 📁 `Подпапка` | ∑ 5 |
| 📄 `заметка.txt` | 1 |

`[Streams]` появляется, только если у открытой папки есть собственные потоки, и ведёт в обычный список потоков со всеми функциональными клавишами. Туда ведут ещё два пути: команда `em_StreamListFolder` (глава 7) для выделенной папки и Alt+Enter на папке с потоками, который предлагает выбор – показать её потоки или её свойства.

## 6. Правила защиты

StreamList различает два уровня, и функциональные клавиши всегда действуют только на тот уровень, который сейчас виден:

| Уровень | F5 / F6 / F8 / Shift+F6 действуют на … |
|---|---|
| Обзор: папки, списки файлов (глава 8) | настоящие файлы и папки |
| Список потоков файла, списки потоков (глава 8) | потоки |

Отсюда следуют такие принципы:

- **Удалённые файлы и папки попадают в корзину.** В плагинах файловой системы удаление иначе было бы окончательным; корзина позволяет исправить ошибку. Сами диски никогда не удаляются и не переименовываются.
- **При копировании потоки сохраняются.** Скопированный файл сохраняет свои потоки на дисках NTFS.
- **Потоки удаляются только там, где они явно показаны как потоки.** F8 на файле удаляет файл – а не отдельные его потоки; и наоборот, F8 в списке потоков никогда не затронет сам файл.
- **Отметки времени сохраняются.** Запись в поток меняет в NTFS дату изменения файла; StreamList затем восстанавливает её.
- **Файлы только для чтения** остаются без изменений; StreamList сообщает причину.

Кто хочет использовать StreamList исключительно как инструмент для потоков, отключает операции с файлами параметром `FileOperations=0`. Тогда StreamList изменяет только потоки и при операциях с файлами в обзоре указывает на эту настройку.

## 7. Прямой переход командой

Для повседневной работы путь через Сетевое окружение неудобен. Четыре пользовательские команды в `usercmd.ini` (рядом с `wincmd.ini`) ведут прямо в нужное место:

```ini
[em_StreamList]
cmd=cd
param=\\\StreamList\%P%N

[em_StreamListDir]
cmd=cd
param=\\\StreamList\%P

[em_StreamListFolder]
cmd=cd
param=\\\StreamList\%P%N\[Streams]

[em_StreamListSearch]
cmd=cd
param=\\\StreamList\!find
```

В разделе *Конфигурация → Настройка → Разное* им можно назначить горячие клавиши; их также можно разместить на кнопках.

| Команда | вызвана в обычной панели на … | Цель |
|---|---|---|
| `em_StreamList` | файле | список потоков этого файла |
| `em_StreamListDir` | любом месте | текущая папка в представлении StreamList |
| `em_StreamListFolder` | папке | потоки этой папки (глава 5) |
| `em_StreamListSearch` | любом месте | свободный поиск (глава 9) |

Команды предназначены для обычной панели; внутри StreamList достаточно Enter.

Заполнители вроде `%P` и `%N` Total Commander заменяет только в поле **Параметры** команды или кнопки, но не в поле **Команда**. Если всё записано там, путь приходит без изменений; StreamList распознаёт это и сообщает об этом.

## 8. Анализ целых дисков с помощью Everything

**Everything 1.5** от voidtools ведёт индекс всех файлов системы и умеет искать в нём и потоки. StreamList использует этот индекс для сумм ∑ и для списков по всем дискам, которые готовы за несколько секунд. Чтение, запись и удаление самих потоков StreamList выполняет непосредственно на диске.

### Однократная подготовка

Чтобы Everything мог искать потоки, нужно проиндексировать два свойства (в Everything примерно в разделе *Сервис → Настройки → Индексы → Свойства*):

- **Имена альтернативных потоков данных**
- **Количество альтернативных потоков данных**

Первая индексация занимает некоторое время; затем Everything сам поддерживает индекс в актуальном состоянии. Если свойства отсутствуют, StreamList сообщает об этом, вместо того чтобы начать поиск, который без индекса длился бы несколько минут.

### Суммы по папкам

Значения `∑` из главы 4 показывают, где сосредоточены потоки:

| Имя | Потоки |
|---|---:|
| 📁 `Users` | ∑ 32 192 |
| 📁 `mingw64` | ∑ 23 044 |
| 📁 `tcmd` | ∑ 961 |
| 📁 `Windows` | ∑ 46 |
| 📁 `Program Files` | |

Большие значения у распакованных программ вроде `mingw64` типичны: при распаковке Windows переносит отметку загрузки ZIP-архива на каждый содержащийся в нём файл.

### Списки в корне

Два списка из главы 3 показывают результаты поиска Everything по всем дискам в виде плоского списка.

**`! Все файлы с потоками`** содержит каждый файл хотя бы с одним потоком; Enter открывает его список потоков. Поскольку записи – настоящие файлы, их можно копировать, перемещать или удалять, как в любом списке результатов поиска.

**`! Загрузки (Zone.Identifier)`** устроен иначе: здесь каждая запись непосредственно соответствует `Zone.Identifier` одного файла.

| Имя | Содержимое | Папка |
|---|---|---|
| 📄 `__init__.py` | …\winlibs.zip | C:\mingw64\lib\python3.9\asyncio |
| 📄 `__init__ [2].py` | …\winlibs.zip | C:\mingw64\lib\python3.9\collections |
| 📦 `setup.zip` | https://example.org/… | C:\Users\…\Downloads |

Колонка **Папка** показывает расположение; одноимённые файлы из разных папок различаются добавкой вроде `[2]`.

### Удаление отметок загрузки

Поскольку каждая запись этого списка – поток, функциональные клавиши действуют напрямую: F3 показывает отметку, **F8 удаляет её** – даже для большого числа выделенных записей за один раз, с обычным подтверждением и индикатором хода Total Commander.

Результат в подробностях:

| | до | после |
|---|---|---|
| Файл | `alrext.exe` | `alrext.exe` – без изменений, та же дата |
| Поток | `alrext.exe:Zone.Identifier` | удалён |
| Windows | предупреждает при открытии | больше не предупреждает |

Отметка выполняет защитную функцию. Для надёжных программ, распакованных самостоятельно, она не нужна; для файлов неясного происхождения её лучше оставить.

## 9. Собственные списки

Оба списка – стандартные. В `StreamList.ini` рядом с плагином можно задать до двадцати собственных поисков, каждый из которых состоит из имени, выражения поиска Everything и, при необходимости, имени потока:

```ini
[Search1]
Name=! Комментарии (ntfs_diz)
Query=alternate-data-stream-names:comment
Stream=Comment
```

Запись `Stream=` определяет вид списка:

| `Stream=` | Вид списка | Запись – это … | Enter / F8 |
|---|---|---|---|
| пусто | список файлов | файл | Enter открывает его потоки; F5/F6/F8 действуют на файл |
| задано | список потоков | именно этот поток файла | F3/F4/F8 действуют прямо на поток |

Как только появляется раздел `[Search1]`, собственные списки заменяют стандартные.

### Свободный поиск

Для меняющихся запросов – например, потоков-меток вроде `MyTag` – в корне есть запись **«! Свободный поиск»**. При входе она показывает результаты последнего запроса. В самом верху находится запись **«! Новый поиск…»**: Enter или двойной щелчок по ней запрашивает любой поисковый запрос Everything; на выбор предлагаются последние десять запросов. Результаты появляются в виде списка файлов: F5, F6 и F8 действуют на файлы, Enter открывает их потоки, а колонка *Preview* показывает содержимое потоков. Результаты сохраняются до следующего нового поиска. Прямо в список ведёт команда `em_StreamListSearch` (глава 7).

## 10. Собственные режимы колонок

Для собственных режимов колонок StreamList предоставляет следующие поля:

| Поле | показывает … |
|---|---|
| `StreamCount` | число потоков; у папок – собственные потоки и сумма ∑ их содержимого, например `1 · ∑ 5` |
| `StreamNames` | имена потоков файла |
| `Content` | самое полезное для каждого уровня: имена, первую строку или источник |
| `Origin` | адрес загрузки (HostUrl) |
| `Referrer` | ссылающаяся страница или архив (ReferrerUrl) |
| `Zone` | Интернет, Интранет, Локальный … |
| `Preview` | первая строка текста потока; у файлов и папок – краткое содержимое их потоков (без Zone.Identifier), например для потоков-меток вроде `MyTag` |
| `Kind` | Текст, Двоичный, Сведения о зоне, Пустой – или **Программа (EXE/DLL)**, если поток содержит исполняемый код. Это известный тайник для вредоносных программ, заслуживающий более пристального внимания. |
| `Folder` | папка файла в списках Everything |
| `Size` | размер файла или потока; в стандартном режиме заменяет колонку размера Total Commander |
| `StreamsTotal` | суммарный размер всех потоков файла или собственных потоков папки |
| `AllocatedSize` | фактически занятое место потока или всех потоков файла либо папки |
| `EntryModified` | последнее изменение записи NTFS – меняется, даже если дата изменения файла сохранена |
| `FullStreamName` | полное имя в виде `C:\…\файл.txt:Comment` |

В обзоре папки также доступны поля других **контентных плагинов**, например ntfs_diz или xytags, поскольку StreamList сообщает Total Commander настоящий файл каждой записи.

Примечание для пользователей тестовой версии: Total Commander перенимает стандартный режим плагина только один раз. Если колонки остаются пустыми, удалите сохранённый режим; при следующем входе StreamList создаст его заново.

---

## 11. Совместная работа с ntfs_diz

ntfs_diz хранит комментарии к файлам в потоках, каждое поле комментария – в отдельном потоке с именем поля (`Comment`, `Comment1` и т. д.). Поэтому в StreamList эти комментарии видны как обычные потоки, которые можно читать клавишей F3 и править клавишей F4. Оба плагина можно использовать одновременно.

## 12. Настройки и журнал

Настройки удобно менять в диалоге: **правый щелчок по StreamList в Сетевом окружении → Свойства.** Он также показывает, доступен ли Everything и проиндексированы ли оба свойства потоков – самая частая причина, если списки остаются пустыми. Там же можно создавать и изменять собственные списки (глава 9) и сразу проверять их кнопкой «Проверить».

Знак **?** в заголовке окна или **F1** открывает это руководство на выбранном языке – сразу на главе, относящейся к выбранному элементу управления. Для этого руководство поставляется в виде справки Windows `StreamList_rus.chm` рядом с плагином; отметку загрузки у этого файла StreamList при открытии удаляет сам, иначе его страницы остались бы пустыми.

После OK StreamList заново читает все настройки; изменения становятся видны при следующем чтении списка (Ctrl+R или смена папки). Перезапуск Total Commander не нужен.

**Журнал.** StreamList записывает каждую операцию с файлами – с датой, временем, действием, источником, целью и результатом – в файл `StreamList_operations.txt` рядом с плагином. Кнопка «Показать журнал…» в диалоге открывает его в виде сортируемого списка с фильтром:

| Время | Действие | Источник | Результат |
|---|---|---|---|
| 2026-10-05 14:03:12 | Поток удалён | `C:\…\setup.zip:Zone.Identifier` | OK |
| 2026-10-05 14:05:40 | В корзину | `C:\Temp\старый.txt` | OK |
| 2026-10-05 14:06:02 | Поток записан | `C:\ADSTest\aa.txt:MyTag` | OK |

Простой просмотр (F3) и временная копия при правке (F4) не записываются, а обратная запись – записывается. Файл представляет собой текст с разделителями-табуляциями; его можно открыть и в Lister, и в электронной таблице.

Диалог и файл равноценны: все настройки хранятся в `StreamList.ini` рядом с плагином и могут изменяться вручную. При первом сохранении из диалога файл переводится в UTF-16, чтобы сохранялись и имена списков, написанные нелатинскими буквами.

| Раздел | Запись | Значение |
|---|---|---|
| `[Options]` | `KeepTime=1` | сохранять дату файла при изменении потоков |
| | `TxtExtension=1` | показывать текстовые потоки без расширения как `.txt` (глава 5) |
| | `FileOperations=1` | операции с настоящими файлами в обзоре (глава 6) |
| `[Protocol]` | `Enabled=1` | записывать операции с файлами |
| | `MaxLines=10000` | не более стольких записей; старые удаляются |
| `[Settings]` | `Language=auto` | язык Total Commander, иначе `eng`, `deu`, `rus`, `ukr`, `dan` |
| `[Everything]` | `Timeout=30000` | ждать Everything не дольше стольких мс |
| | `MaxResults=100000` | не более стольких записей в списке |
| | `Exclude=!\$Recycle.Bin\` | добавляется к каждому поиску; скрывает корзину |
| | `FolderQuery=…` | что учитывается в суммах ∑; пусто – отключено |
| | `FolderCacheMinutes=5` | сколько минут суммы используются повторно |
| `[Search1]` … `[Search20]` | | собственные списки (глава 9) |

О `FolderQuery`: службы синхронизации вроде Dropbox снабжают каждый файл собственным потоком и тогда доминируют в суммах. С `FolderQuery=alternate-data-stream-names:zone.identifier` суммы ограничиваются отметками загрузки.

## 13. Примечания и ограничения

- Потоки теряются, как только файл копируется на FAT32 или exFAT, отправляется по электронной почте или загружается во многие облачные сервисы.
- Копирует ли Total Commander потоки, определяет параметр `CopyStreams` (см. справку Total Commander).
- Сетевые диски и CD не показываются в корне, но доступны через `em_StreamListDir`.
- Размеры и отметки времени в колонках передаются как текст, потому что иначе Total Commander не всегда надёжно показывает числа в строках папок. Поэтому размеры выровнены вправо, а время записано в формате `ГГГГ-ММ-ДД чч:мм:сс`; так и сортировка остаётся правильной.
- Суммы ∑ берутся из индекса Everything, значения отдельных файлов StreamList читает прямо с диска. Сразу после изменений они могут ненадолго расходиться.
- Если Everything не запущен, суммы ∑ остаются пустыми, а списки показывают сообщение. StreamList повторяет попытку примерно через 30 секунд; перезапуск Total Commander не нужен.

## 14. Поиск неисправностей

Для поиска неисправностей есть **отладочная версия**. Она пишет журнал в файл `StreamList_debug.log` рядом с плагином; первая строка показывает, какой файл плагина и какой файл настроек на самом деле загружает Total Commander:

```text
=== DEBUG-Build geladen: C:\…\StreamList.wfx64 | INI: C:\…\StreamList.ini (vorhanden) | Log=1 ===
```

Сообщения об ошибках с этим журналом и кратким описанием принимаются через форум Total Commander или GitHub. Обычная версия не содержит кода журналирования.

## 15. Переводы

`StreamList.lng` содержит английский, немецкий, русский, украинский и датский языки. Переводы на другие языки автор с радостью примет через форум Total Commander или GitHub.
