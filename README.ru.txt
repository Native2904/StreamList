StreamList 0.2.0
Альтернативные потоки NTFS для Total Commander (плагин файловой системы, 32/64 бит)
Автор: Native2904 (форум TC / GitHub)   Лицензия: MIT


ЧТО ТАКОЕ АЛЬТЕРНАТИВНЫЕ ПОТОКИ ДАННЫХ?
---------------------------------------
В NTFS файл, помимо обычного содержимого, может хранить дополнительные
скрытые «подфайлы». Проводник их не показывает, в размер файла они не
входят, но остаются с файлом, пока он находится на NTFS.

Почти наверняка они есть и у вас: браузеры добавляют к каждой загрузке поток
«Zone.Identifier». В нём записана зона (Интернет) и часто адрес, откуда
получен файл, — отсюда предупреждение Windows «Этот файл получен с другого
компьютера».

Попробуйте сами (командная строка):
  echo Основное содержимое > test.txt
  echo Привет из потока > test.txt:secret
  dir /r


ТРЕБОВАНИЯ
----------
Total Commander 7.5 или новее, Windows 7 или новее, диски NTFS.


УСТАНОВКА
---------
Откройте архив в Total Commander и подтвердите установку.
После этого StreamList появится в «Сетевом окружении».


ИСПОЛЬЗОВАНИЕ
-------------
Сетевое окружение -> StreamList показывает диски NTFS. Ниже вы переходите
по обычным папкам, но файлы отображаются как папки: Enter на файле открывает
список его потоков.

Прямой вход из обычной панели — добавьте в usercmd.ini (рядом с wincmd.ini):

  [em_StreamList]
  cmd=cd
  param=\\\StreamList\%P%N

Затем назначьте горячую клавишу: Конфигурация -> Настройка -> Разное.
Используйте её в обычной панели; внутри StreamList просто нажимайте Enter.

Внутри файла (список потоков):
  F3          просмотр потока
  F4          правка потока — при сохранении он записывается обратно в файл
  F5          копировать потоки наружу (станут обычными файлами)
  F5 внутрь   копировать обычные файлы в список потоков: станут потоками
  F7          создать новый пустой поток
  Shift+F6    переименовать поток
  F6          переместить потоки наружу
  F8          удалить потоки
  Alt+Enter   сведения о потоке; на файле в режиме папок — свойства Проводника


СТОЛБЦЫ
-------
При входе StreamList показывает: Размер | Дата | Потоки | Содержимое | Источник
  Режим папок:     число потоков, их имена, адрес загрузки
  Список потоков:  первая строка текста каждого потока (двоичные — в hex)

Поля для собственных наборов столбцов ([=streamlist.<поле>]):
  Streams, StreamNames, Origin, Referrer, Zone, Content, Preview, Kind

Контентные плагины других авторов (например, ntfs_diz, xytags) тоже работают
в режиме папок, так как StreamList сообщает настоящий файл за каждой записью.


БЕЗОПАСНОСТЬ
------------
- StreamList никогда не удаляет, не переименовывает и не создаёт настоящие
  файлы и папки.
- Потоки можно удалять или перемещать только из списка потоков их файла.
  F8 на файле или папке в режиме папок лишь показывает предупреждение.
- Дата и время файла сохраняются при изменении его потоков (KeepTime).
- Файлы только для чтения: записать поток нельзя, StreamList сообщит об этом.


СОВМЕСТИМОСТЬ С NTFS_DIZ
------------------------
ntfs_diz хранит каждое поле комментария как поток с именем поля
(Comment, Comment1, ...). StreamList показывает эти потоки, их можно читать
и править — оба плагина можно использовать одновременно.


НАСТРОЙКИ (StreamList.ini рядом с плагином)
-------------------------------------------
  [Options]  KeepTime=1     1 = сохранять дату файла при изменении потоков
  [Settings] Language=auto  auto = язык TC, иначе eng/deu/rus/ukr/dan
  [Debug]    Log=0          1 = писать StreamList_debug.log рядом с плагином


ПОЛЕЗНО ЗНАТЬ
-------------
- Потоки теряются при копировании на FAT32/exFAT, отправке по почте и
  загрузке во многие облачные сервисы.
- Если Total Commander не копирует потоки, см. параметр CopyStreams в
  wincmd.ini (справка TC).
- Сетевые диски и CD не показываются в корне, но открываются горячей
  клавишей или командой cd \\\StreamList\X:\...
- Потоки папок пока не отображаются.
- Горячая клавиша работает и внутри StreamList, но тогда TC показывает имя
  плагина в пути дважды. Внутри плагина лучше нажимать Enter.


ПЕРЕВОДЫ
--------
